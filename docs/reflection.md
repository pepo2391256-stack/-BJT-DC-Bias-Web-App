## 1. ทำไมการเปิด `templates/index.html` ตรง ๆ จึงไม่เท่ากับการรัน Flask?

เพราะ `index.html` เป็น **Jinja template** ไม่ใช่หน้าเว็บสำเร็จรูป ข้างในมี `{{ form.vcc }}`,
`{% if result %}` และ `url_for(...)` ซึ่งมีแต่ Flask/Jinja เท่านั้นที่แทนค่าได้
ถ้าเปิดด้วย `file://` จะเห็นโค้ด Mustache ค้างหรือค่าว่าง และไม่มีอะไรคำนวณ
เพราะไม่มีการส่ง HTTP request ไปยัง Python, ไม่มี route `/calculate`
และไม่มีฟังก์ชัน `calculate_dc_bias` ทำงาน

## 2. ฟอร์มส่งข้อมูลไปยัง Python อย่างไร?

`<form method="post" action="/calculate">` ทำให้เบราว์เซอร์รวมค่าจาก `<input name="...">`
เป็น `application/x-www-form-urlencoded` แล้วส่ง POST ไปที่ Flask
route `calculate()` อ่านค่าด้วย `request.form.get("vcc")` ฯลฯ
จากนั้นเรียก `calculate_dc_bias(...)` ใน `dc_bias.py` คำนวณ
และ `render_template("index.html", ...)` ส่ง HTML ที่มีผลลัพธ์กลับไปแสดง

## 3. ถ้าแก้สมการใน `dc_bias.py` ต้องแก้ `templates/index.html` ด้วยหรือไม่?

**ไม่ต้อง** ตราบใดที่รายการอินพุต/เอาต์พุตยังเหมือนเดิม เพราะ HTML ไม่มีสมการฟิสิกส์
มีเพียงการแสดงค่าที่ Flask ส่งมา (`{{ result.vb }}`) การแก้สมการจึงจบใน `dc_bias.py`
และเทสต์จะจับว่าผลเปลี่ยนไปหรือไม่ ถ้าเพิ่มตัวแปรใหม่ที่ต้องแสดง เช่น `VTH`
จึงต้องแก้ template เพิ่ม

## 4. ทำไมผลที่อยู่นอก Active Region จึงต้องมี Warning?

สมการที่ใช้เป็น **Forward-Active approximation** ซึ่งสมมติว่า β คงที่, VBE ≈ 0.7 V
และรอยต่อ Collector ต้องอยู่ในช่วงที่เหมาะสม เมื่อ `VTH ≤ VBE` ทรานซิสเตอร์จะ Cutoff
(IB ≈ 0) และเมื่อ `VCE` ต่ำมากจะเข้าสู่ Saturation ซึ่ง IC จริงถูกจำกัดด้วยวงจร
ไม่ใช่ `β·IB` อีกต่อไป ตัวเลขที่สมการให้มาจึงอาจติดลบหรือสูงเกินจริง
Warning จึงจำเป็นเพื่อไม่ให้ผู้ใช้นำค่าไปใช้ผิด และเพื่อบอกขอบเขตของแบบจำลอง
