Calculation details (ค่าที่แทนในสมการ)
  • VTH = VCC · R2 / (R1 + R2) = {{ form.vcc }} × {{ form.r2 }} / ({{ form.r1 }} + {{ form.r2 }}) = {{ result.vth }}
  • RTH = R1 R2 / (R1 + R2) = {{ result.rth }}
  • IB = (VTH − VBE) / (RTH + (β+1) RE) = {{ result.ib }}
  • IC = β IB = {{ form.beta }} × {{ result.ib }} = {{ result.ic }}
  • IE = (β+1) IB = {{ result.ie }}
  • VE = IE RE = {{ result.ie }} × {{ form.re }} kΩ = {{ result.ve }}
  • VB = VE + VBE = {{ result.ve }} + {{ form.vbe }} V = {{ result.vb }}
  • VC = VCC − IC RC = {{ form.vcc }} − {{ result.ic }} × {{ form.rc }} kΩ = {{ result.vc }}
  • VCE = VC − VE = {{ result.vc }} − {{ result.ve }} = {{ result.vce }}

Model Assumptions & Region Limits

  • Forward-active approximation with constant β และ VBE (ไม่คำนวณ Early effect, leakage, temperature drift หรือ parasitic)
  • Cutoff เมื่อ VTH ≤ VBE → IB = IC = IE = 0, VE = 0, VC = VCE = VCC
  • Saturation เมื่อ VCE < 0.3 V → ค่า IC จาก β·IB สูงกว่าความจริง ต้องอ่าน Warning ก่อนใช้
  • ตัวต้านทานกรอกเป็น kΩ และถูกแปลงเป็น Ω ก่อนคำนวณ; ทุกค่าที่แสดงมีหน่วยกำกับ
